# IndustrialFlow

IndustrialFlow is a modular industrial process simulator focused on the design,
operation and optimisation of real industrial plants.

## Current Features

- Resource simulation
- Utility networks
- Steam
- Boilers
- Chippers
- Process control
- PI controllers
- Trends
- Machine components

## Planned Features

- SCADA interface
- Maintenance
- Research
- Chemistry
- Multiple industry packages
